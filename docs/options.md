# Every argument

A reference for every command, option and script flag, with when to use each. For a guided
walkthrough, read [How to train](training.md) and [How to use](usage.md) first.

You normally only type the `/handwritten …` commands (or plain English). Claude runs the scripts
for you; they're listed in [Scripts](#scripts) for transparency, debugging, and anyone who wants to
run a step by hand.

## /handwritten commands

```
/handwritten train <photos or folder> [--profile NAME]
/handwritten template maths
/handwritten identity train <photo> [--profile NAME]
/handwritten status [--profile NAME]
/handwritten gaps
/handwritten <images or folder> [--continuous] [--identity] [--pdf] [--clean] [--ink blue|black|#hex] [--seed N] [--profile NAME]
```

Claude reads the arguments, so plain English works for all of them.

### `train <photos or folder>`

Learns your handwriting from photos of pages you wrote, or adds pages to an existing profile.

- **When:** the first time, and whenever you have more pages to add (to fill missing characters,
  add variety, or add the filled-in maths template).
- **Takes:** image files and/or folders. Template pages (with four black corner squares) are
  detected and read automatically; everything else is treated as an ordinary page of writing.
- **Note:** photos already in the profile are skipped, so you can point it at the same folder again
  after adding photos to it.
- Guide: [How to train](training.md).

### `template maths`

Makes the printable maths template: `./handwritten_templates/maths_template.pdf` (6 A4 pages, 487
boxes) plus a PNG of each page.

- **When:** after your first training, if you write maths and `status` shows missing symbols, or
  you want your own superscripts, roots, fractions, sums and matrix brackets.
- `maths` is currently the only template.
- Guide: [The maths template](training.md#the-maths-template).

### `identity train <photo>`

Learns the serial number / name block you write in the top-left corner of an answer sheet, from
one photo of a page with the block on it.

- **When:** you want `--identity` to put the block on the first page of your outputs.
- Training again replaces the block.
- Guide: [The identity block](training.md#the-identity-block).

### `status`

Shows whether a profile exists and what it covers: characters and variants per group, missing and
thin characters, joins, maths pieces, tall brackets, the identity block, measured style (x-height,
slant, stroke width, line pitch), any saved settings, and the paths to `preview.png` and the
specimen sheets.

- **When:** after training, before a big job, or when an output used stand-ins and you want to see
  what's missing.

### `gaps`

Not built yet. For now it lists the characters `status` reports as missing and suggests the maths
template for symbols.

### `<images…>` (generate)

Anything that isn't one of the commands above is treated as images to write out. See
[Generation options](#generation-options) and [How to use](usage.md).

### `--profile NAME`

Works with every command. Uses the profile `~/.handwritten/profiles/NAME/` instead of `default`.

- **When:** you keep more than one handwriting (yours and a friend's, or print and cursive), or
  want to experiment without touching your main profile.

## Generation options

### `--continuous`

All inputs flow into one document instead of each starting on a new page.

- **Default:** off (per-image: each input starts a new page; a long input continues onto
  `page_NNa`, `page_NNb` …).
- **When:** the inputs are pieces of one document (consecutive screenshots of an article, the pages
  of one set of notes). A paragraph split across two images is rejoined.
- **Not when:** the inputs are separate questions or documents that should each start on their own
  page.

### `--pdf`

Also writes `handwritten.pdf` with every page in order, each exactly A4 at 300 DPI. The PNGs are
still written.

- **Default:** off (PNG only).
- **When:** you need a single file to print, upload or send.
- **Note:** the PDF's metadata marks it as generated by the skill.

### `--clean`

A flat, white "scan" instead of the phone-photo look.

- **Default:** off. Pages look like phone photos of paper: fine paper grain, a slightly warm white,
  a soft lighting gradient and shadow from one edge, a slight perspective tilt, a little blur,
  sensor noise and JPEG softness. Every page gets its own random settings.
- **When:** you'll print the pages, want the crispest result, or the photo look doesn't suit.

### `--ink blue|black|#rrggbb`

The ink colour.

- **Default:** `blue` (ballpoint blue, RGB 25, 45, 140).
- `black` is a soft black (RGB 28, 28, 32). Any 6-digit hex colour works, with or without `#`
  (`--ink "#1a237e"`).
- **When:** you write in black, or want to match a specific pen.

### `--identity`

Writes your trained identity block (serial number and name, with the line under it and the line
down its right side) in the top-left corner of the **first page of the output only**, and starts the
text below it.

- **Default:** off.
- **When:** the output is an answer sheet or form that needs your details at the top.
- **Needs:** an identity block trained with `identity train`. Without one, Claude asks for a photo
  and trains it first.
- **Note:** in per-image mode too, only the very first page gets the block (`page_01` or
  `page_01a`).

### `--seed N`

Fixes the random choices: which variant of each letter, jitter, baseline wave, margin, and the photo
effect.

- **Default:** a random seed, printed after every run and saved in `report.json`.
- **When:** you want to reproduce a result exactly, re-render after fixing a typo without changing
  the look, or say "the same as last time".
- **Also:** if one glyph looks bad, re-rendering *without* a seed (or with a different one) picks
  different variants.
- **Note:** the identity block has its own random numbers, so a seed gives the same text writing
  with or without `--identity`.

### `--profile NAME`

See [above](#--profile-name).

### Line spacing for one run

Ask for it in plain English (*"use 8 mm line spacing for this one"*). Claude passes
`--line-pitch 8` to `render.py`. It doesn't change the profile.

## Training adjustments

You don't need these normally. Claude uses them when a photo needs help, or you can ask for them.

| What you say | What Claude does | When |
|---|---|---|
| *"these are B5 pages, 176 × 250 mm"* | `preprocess.py --page-mm 176x250 --redo` | Your paper isn't A4 or US Letter. A wrong size makes the writing too big or too small (check the x-height in `status`). |
| *"the page wasn't found in photo 3"* | finds the corners and runs `preprocess.py --corners …` | The report says `page edges NOT found`, `page found (unknown)`, or shows a large deskew: the desk was detected instead of the page. |
| *"reject 12, 57 and 103"* | `build_profile.py --reject 12,57,103` | Bad variants on the specimen sheets. Numbers change every rebuild, so use the latest sheets. Rejections are remembered across rebuilds. |
| *"reject suspect 12"* | `build_profile.py --reject s12` | A glyph on a `suspects_NN.png` sheet is really a different character. |
| *"capture the tall brackets on that page"* | `tall_glyphs.py <sample>` then labels | Your notes have brackets or braces around matrices. |
| *"read template page 3 again"* | `read_template.py --redo <photo>` | You replaced a poor template photo with a better one. |

## Profile settings

Values you choose that override what training measured. They're saved in the profile's
`settings.json` and survive retraining.

| Setting | Range | What it does | Say |
|---|---|---|---|
| `line_pitch_mm` | 6–15 mm | Distance between lines of writing. | *"set line spacing to 9.6 mm"*; *"use the measured spacing again"* to remove it |

Changing a setting regenerates `preview.png` so you can see the effect.

## Scripts

All scripts live in `scripts/`. Run them with the skill's own Python, after creating it once:

```bash
cd ~/.claude/skills/handwritten
bash scripts/setup_env.sh
~/.handwritten/.venv/bin/python scripts/status.py
```

Every script accepts `--profile NAME` (default `default`) unless noted.

### `setup_env.sh`

```
bash scripts/setup_env.sh
```

Creates `~/.handwritten/.venv` with the first Python 3.9+ it finds (trying 3.13 down to 3.10, then
`python3`) and installs `requirements.txt`. Safe to run every time: it does nothing unless
`requirements.txt` changed.

### `status.py`

```
status.py [--profile NAME] [--require]
```

| Flag | Meaning |
|---|---|
| `--require` | Exit with code 2 and a "train first" message when there's no usable profile. Generation runs this first. |

### `read_template.py`

```
read_template.py [--profile NAME] [--redo] PHOTO_OR_FOLDER...
```

Reads photos of filled-in template sheets into training samples and lists photos that aren't
template pages. Writes `cells.png` per page for checking.

| Flag | Meaning |
|---|---|
| `--redo` | Read again photos of template pages that were read before (after replacing a poor photo). |

### `preprocess.py`

```
preprocess.py [--profile NAME] [--page-mm WxH] [--redo] [--corners x,y,x,y,x,y,x,y] PHOTO_OR_FOLDER...
```

Turns photos into flat, clean 300 DPI ink maps, one sample folder each. Writes `preview_top.jpg`,
`preview_bottom.jpg` and `rows.png` for transcribing.

| Flag | Meaning |
|---|---|
| `--page-mm WxH` | Real paper size in mm, e.g. `176x250` (B5). Without it, A4 or US Letter is detected. |
| `--redo` | Process photos again that are already in the profile (needed with a new `--page-mm`). |
| `--corners` | The page's corners in pixels, top-left, top-right, bottom-right, bottom-left, when detection fails. Exactly one photo per run; implies `--redo`. |

### `segment_freeform.py`

```
segment_freeform.py [--profile NAME] [--force] [SAMPLE_ID...]
```

Splits each sample (all of them, or the ones named) into lines, words and pieces of ink, guided by
`transcript.txt`. Writes `segments.json`, `lines.png`, `labels.txt` and the contact sheets in
`sheets/`.

| Flag | Meaning |
|---|---|
| `--force` | Segment again even if the transcript hasn't changed. |

### `set_labels.py`

```
set_labels.py SAMPLE_DIR WORD_ID=SPLIT [WORD_ID=SPLIT ...]
```

Writes label corrections to a sample's `labels.txt`. A split has one part per piece of ink,
separated by `|`, and the parts must spell the word: `w026=V|a|r|i|ab|l|es|.`. An empty part marks a
stray fragment (`i||t`), `\|` is a bar written in the word, and `?` skips the word. Takes no
`--profile` (the sample directory says which profile).

### `tall_glyphs.py`

```
tall_glyphs.py [--profile NAME] SAMPLE_ID              # find tall strokes, write tall_sheet.png
tall_glyphs.py [--profile NAME] SAMPLE_ID 1={ 2=} 3=[  # label them by number
```

Labels may be `(`, `)`, `[`, `]`, `{`, `}` or `|`. Unlabelled strokes are ignored. Run
`build_profile.py` afterwards.

### `build_profile.py`

```
build_profile.py [--profile NAME] [--reject 12,57,s3,...]
```

Rebuilds the profile from every labelled sample: glyphs, ligatures, maths pieces, style
measurements, `coverage.txt`, `specimen_NN.png`, `suspects_NN.png` and `preview.png`.

| Flag | Meaning |
|---|---|
| `--reject` | Comma-separated numbers from the latest specimen sheets (`12`) or suspect sheets (`s12`) to stop using. Saved in `rejected.json`, so they stay rejected. |

### `identity.py`

```
identity.py train PHOTO --line "ROW 1" --line "ROW 2" [--profile NAME] [--corners x,y,x,y,x,y,x,y] [--reject 3,17]
identity.py show [--profile NAME]
```

| Flag | Meaning |
|---|---|
| `--line` | One row of the block's text exactly as written, in order. Repeat for each row. |
| `--corners` | The page's corners in pixels when the page edges aren't found; snapped to the paper's edges. |
| `--reject` | Numbers of badly cut characters on `identity/sheet.png`; another copy of the same character from the photo is used, or the profile's ordinary one. |

`show` prints the trained rows, the size of the capitals and where the two lines run; it exits with
code 2 if no block is trained.

### `template_sheets.py`

```
template_sheets.py NAME [--out DIR]
```

Draws the printable template `templates/NAME.json` as a PDF plus one PNG per page. No `--profile`.

| Flag | Meaning |
|---|---|
| `--out` | Folder for the PDF and PNGs (default: the current directory; the skill uses `./handwritten_templates`). |

### `settings.py`

```
settings.py [--profile NAME]                      # show
settings.py [--profile NAME] line_pitch_mm=9.6    # set
settings.py [--profile NAME] line_pitch_mm=       # remove (back to the measured value)
```

### `render.py`

```
render.py --out DIR [--profile NAME] [--continuous] [--clean] [--seed N] [--ink blue|black|#hex]
          [--line-pitch MM] [--identity] [--pdf] TRANSCRIPT...
```

Writes transcripts (one per input, in the [transcript format](usage.md#the-transcript-format)) out
by hand.

| Flag | Meaning |
|---|---|
| `--out DIR` | Output folder (required). |
| `--continuous` | Flow all transcripts into one document. |
| `--clean` | No phone-photo effect. |
| `--seed N` | Fix the random variation. |
| `--ink` | `blue` (default), `black` or a hex colour. |
| `--line-pitch MM` | Line spacing for this run only. |
| `--identity` | Draw the identity block on the first page. |
| `--pdf` | Also write `handwritten.pdf`. |

Exits with code 2 when there's no profile, or no identity block with `--identity`.

### Modules without a command line

`common.py` (paths, character sets, helpers), `photo_effect.py` (the phone-photo look),
`template_extras.py` (maths pieces from template pages for the profile).

| Variable | Default | Meaning |

## Files

**A profile** (`~/.handwritten/profiles/<NAME>/`):

| Path | What |
|---|---|
| `profile.json` | glyphs, ligatures, maths pieces, style measurements, coverage |
| `glyphs/<hex>/…png`, `ligatures/…` | every cut-out character and join (300 DPI) |
| `coverage.txt` | the coverage report `status` prints |
| `preview.png` | a test sentence written with the profile |
| `specimen_NN.png`, `suspects_NN.png` | review sheets |
| `rejected.json` | glyphs rejected in review |
| `settings.json` | your settings (line spacing) |
| `identity/` | the identity block: `identity.json`, its characters, `sheet.png`, `preview.png` |
| `samples/<id>/` | one folder per training photo: `original.<ext>`, `ink.png`, `transcript.txt`, `segments.json`, `labels.txt`, review images |

**An output** (`./handwritten_out/<YYYYMMDD-HHMMSS>/`): `page_NN.png`, `handwritten.pdf` (with
`--pdf`), `report.json`, `transcripts/input_NN.md`, `qa/page_NN_top.jpg` and `_bottom.jpg`.
